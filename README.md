# 51 ARCHIVE

Waitlist + store front for the 51 Archive clothing brand.

## Pages
- `index.html` — email waitlist / early access
- `store.html` — Beanie 001 product page (pink/red camo)

## Local preview
Open `index.html` in a browser.

Waitlist currently saves emails in the visitor’s browser (`localStorage`). Hook the form to Formspree, Buttondown, or Mailchimp when you want real inbox capture.

## GitHub Pages
Repo Settings → Pages → Deploy from branch `main` / root.
Site will live at `https://elytenn6-arch.github.io/51-archive/`
